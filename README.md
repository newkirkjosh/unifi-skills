# UniFi skills

Reusable UniFi API and diagnosis guidance, with read-only defaults and tested credential-safe helpers. Network-specific inventory, secrets and findings belong in private project notes.

## Skill

`unifi`: select API access, inspect network evidence and perform explicitly approved changes.

Extracted from newkirkjosh/skills at 952c096b5ce0b7d11ee4d9727edd162e0df8da85. MIT; see LICENSE.

## Install

After cloning, run `bash scripts/install.sh` from the main checkout. This links the catalog into Claude Code and Codex skill directories and refuses foreign-name collisions. Remove a former catalog’s retired link through its own installer before transferring ownership.
